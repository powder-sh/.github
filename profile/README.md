**powder** is an open-source, single-tenant deploy platform for your own Hetzner boxes: push to GitHub, it builds on the target server, health-checks the result and swaps it in. Encrypted env vars, verified Postgres backups to S3, preview deploys per branch, cron and uptime in one dashboard.
