**powder** is an open-source deploy platform for your own servers: git push, it builds on your box, health-checks the result and swaps it in. Single-tenant by design: one install, your servers, nobody in between. Encrypted env vars, verified Postgres backups to S3, preview deploys per branch, cron and uptime in one dashboard.
